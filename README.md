# 🐍 Python Basics + Games

A beginner-friendly repository for learning Python programming through simple examples, practice programs, and fun games.

---

## 📌 About This Repository

This repository is designed to help beginners understand Python programming in a simple and practical way.  
It includes basic programs and small games to improve logic-building and coding skills.

---

## 🚀 How to Run

### 1. Install Python
Make sure Python is installed on your system:
```bash
python --version
```

---

### 2. Clone the repository
```bash
git clone https://github.com/ruturajjadhav07/python-for-beginners.git
```

---

### 3. Go to project folder
```bash
cd python-for-beginners
```

---

### 4. Navigate to specific folder (if needed)
```bash
cd folder_name
```

---

### 5. Run any Python file
```bash
python filename.py
```

If `python` doesn’t work:
```bash
python3 filename.py
```
